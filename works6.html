概要
テンプレート販売事業向けに、メンズ眉毛サロンを想定したランディングページテンプレートを制作いたしました。
目的
問い合わせ・来店予約につながる汎用型LPテンプレートの開発
ターゲット
身だしなみや美容意識の高い男性（20〜40代向け）
コンセプト
清潔感と信頼感を重視した、モダンで洗練されたメンズ美容LP
デザイン
シンプルで余白を活かした構成とモノトーンを基調とした配色に、アクセントカラーを加えることで洗練された印象を演出しました。 スマートフォンでの視認性と操作性を重視し、視線誘導を意識した縦長LP構成を採用しています。 ワイヤーフレームをもとに、業種展開しやすいテンプレート仕様としてデザイン・コーディングまで一貫して制作しました。
制作期間
企画 / 情報設計 / デザイン / コーディング：3週間
使用ツール
Figma / Visual Studio Code

制作プロセス

01

構成確認・要件整理

提供されたワイヤーフレームをもとに、サービス訴求と問い合わせ導線を整理しました。

02

業種特化デザイン設計

メンズ向けに信頼感とスタイリッシュさを重視し、モノトーンを基調とした配色と余白構成を設計しました。

03

ビジュアル制作・素材選定

サロンの清潔感と技術力が伝わる実写素材を選定し、視覚的訴求力を高めました。

04

コーディング・レスポンシブ対応

スマートフォン閲覧を最優先に設計し、すべてのデバイスで快適に操作できるLPを実装しました。
