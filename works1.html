サイトを見る
概要
予約促進を目的としたホテルのホームページを制作いたしました。
目的
予約の増加
ターゲット
仕事に疲れた人（20〜50代向け）
コンセプト
自然に囲まれた温泉付きのホテル。高級感×リラックス（20〜50代向け）
デザイン
高級感を出すためにシックな配色と余白をたっぷりと使用しました。自然の温かみを出すことで高級感の中にもリラックスできる雰囲気を演出しました。サイトを訪れた方に泊まりたい！と思っていただけるように、心に残る写真を選び工夫しました。
制作期間
企画 / 情報設計 / デザイン / コーディング：4週間
使用ツール
Figma / Visual Studio Code

制作プロセス

01

ヒアリング・コンセプト設計

施設の強みやターゲット層を整理し、予約につながるコンセプトと訴求ポイントを明確化しました。

02

導線設計・構成プランニング

滞在イメージが自然に伝わるよう、魅力紹介から予約誘導までの流れを意識してLP構成を設計しました。

03

ビジュアルデザイン制作

非日常感と高級感を演出する写真選定と配色で、心に残るデザインを制作しました。

04

レスポンシブ実装

スマートフォンでも快適に閲覧・予約できるよう、操作性を重視したコーディングを行いました。
